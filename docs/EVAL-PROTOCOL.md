# 人评协议（阶段 5，v0 草案）

> 数值断言能证明"渲染符合契约与设计意图"，证明不了"观众觉得像活人"。
> 本协议定义最小可行的人评流程；结果按版本公开，**失败样片保留不删**。

## 片源

- 每次评审取 **6 段 4~6s 成片**：3 段 pinyin 模式 + 3 段 estimated 模式（诚实对比），
  覆盖：陈述句、带！强调句、带？疑问句；同一角色（no4）。
- 顺序**随机化**（评审者本地 shuffle），不告知模式。

## 问卷（每段 4 题，5 分制）

1. 口型与"应该发的音"对得上吗？（1=完全错位，5=自然同步）
2. 人物看起来"活"吗？（眼神/眨眼/头部微动）——1=木偶，5=自然
3. 情绪读得出来吗？（强调/疑问的区分）——1=读不出，5=明显
4. 有一眼假/出戏的瞬间吗？（开放字段，记录帧号）

## 判定

- 题均分 ≥3.5 且第 1 题 ≥4.0 → 该模式通过本轮；
- 低于线 → 记录最差样片与帧号，转成缺陷单（evidence 进 ROADMAP §11 式记录）。

## 执行与留痕

- 评审者 ≥3 人（含作者外 1 人）；结果写 `docs/eval/<date>.md`
  （原始评分 + 片源 hash + 结论），**不通过的不删片**。
