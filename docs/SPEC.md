# 纯代码主播 · B 路线规格（设定稿 → SVG 复刻 → 参数驱动表演）

> 2026-10-27 定。老板原话：「太丑了，选B吧。」并在更早一轮给出条件：
> 「纯代码去优化，不然后面制作起来会有很多麻烦。除非能依靠代码去精准控制角色表情。」

## 0. 为什么是这条路（而不是继续抠图，也不是继续凭空画）

| 方案 | 长相 | 表情控制 | 量产风险 |
|:--|:--|:--|:--|
| 生图定妆稿 + 抠口型贴图 | 好 | 差（只能换图） | **高**：漂移/接缝/两层鼻子/眉毛断层，实测 6 个假设只成立 2 个 |
| 纯代码凭空画脸 | 差（clip-art） | 好 | 低但**审美不收敛**：三版迭代仍是剪贴画 |
| **B：设定稿 → SVG 复刻 → 参数表演** | 由设定稿决定 | **好（16 参数）** | 低：几何是代码，改动可复现 |

关键判断：**设定稿只定"长什么样"，不进渲染链路**。渲染永远是 SVG 几何，
所以不存在抠图、补丁、贴图漂移——那类问题在结构上被消灭，而不是被调参调掉。

## 1. 设定稿交付规格（硬约束，不满足就复刻不了）

出图 prompt 里必须写死这几条：

1. **扁平色块**，7 色以内，**禁渐变、禁噪点、禁笔触、禁照片级明暗**。
   —— 原因：渐变与噪点无法用有限几何复刻，一复刻就"神似形不似"，越改越脏。
2. **正面、平视、中性表情、闭嘴、睁眼**、头肩、居中、留边。
   —— 原因：斜侧脸的眼/鼻/嘴位置是投影结果，参数化难度翻倍。
3. **分层清晰**：头发压脸、眼镜压脸、衣领压脖，每层边界可辨。
   —— 原因：复刻时按层建 `<g>`，层序错了就会出现"眼镜被头发盖住"这类错。
4. **单一纯色背景**。
5. 无文字/签名/水印/边框。
6. **嘴宽 ≥ 0.36 × 脸宽、唇厚 ≥ 0.05 × 脸高**。
   —— 2026-10-30 实测候选 4：嘴宽只有脸宽的 0.28，成片里口型能"认"但气势弱，参数化补不回来
   （口型幅度以 lipW 为基准，嘴小则所有口型都小）。
7. **颈部不要大面积裸露**（禁深 V / 大开领 / 无领）。
   —— 候选 4 是开领西装，脖子+胸口同色连成一片，成片里像"长颈族"，且 `skinBox` 兜底也无法把它切开。
   设定稿阶段加个领子/领口最省事。

## 2. 九部件拆解（对称部件用一个组件 + mirror 参数）

| 部件 | 复刻要点 | 参数化的部分 |
|:--|:--|:--|
| 头发 | 外轮廓 + 发际线 + 发流高光带（不是"填充三角"） | 跟随头部整体变换 |
| 眉 ×2 | 眉峰位置、内端/外端厚度差 | `brow` 抬高、`browIn` 内压 |
| 眼 ×2 | 杏形裂口 + 上睑线 + 卧蚕 + 虹膜 | `lid` 开合、`gazeX/Y` 视线、`blink` |
| 鼻 | **只允许一组结构**：鼻梁受光 + 鼻头一条弧 + 两鼻孔 + 一道底影 | 无（跟随头部） |
| 嘴 | 唇形外框 + 口腔 + 牙 + 舌 + 唇高光 | `mouthOpen/Wide/Round`、`smile` |
| 耳 ×2 | 半露，被鬓角压住 | 无 |
| 颈 | 含胸锁乳突肌与下颌投影 | `jaw` 联动 |
| 肩/躯干 | 斜方肌 → 肩峰 → 袖山 → 胸廓，**必须有袖子与暗缝** | `nod`/`tilt` 带出 |
| 服装 | 领型 + 罗纹/褶皱线（细、低对比） | 无 |

## 3. 表情契约（已实现于 `src/anchor-code/types.ts`）

`Pose` 16 参数：`brow / browIn / lid / smile / gazeX / gazeY / mouthOpen / mouthWide / mouthRound / jaw / tilt / nod / yaw / blink`（+ `cheek` 预留）。

- **口型表 `VISEME`**：M/A/O/E/I/U 六项，每项是「张口 + 横展 + 收圆 + 下颌」的组合。
- **情绪表 `MOODS`**：中性/强调/怀疑/轻松/认真，作为姿态偏移叠加在中性脸上，可连续插值。
- 二者都是纯数据，可被 spring、字级时间戳、重音检测任意驱动。

## 4. 复刻验收：把"像不像"变成可测

光靠眼睛看会陷入"我觉得可以了"。用三条硬校验：

1. **叠加 diff**：把 SVG 渲染帧与设定稿按同一包围盒对齐（头宽、眼距、鼻底到嘴距三个锚点），
   算逐像素色差图；`mean ΔE` 与"偏差最大的 5 个区域"必须是可解释的（比如"眼镜框粗了 2px"）。
2. **比例表**：眼距 / 眼宽 / 鼻长 / 嘴宽 / 下颌宽度 / 头肩比，六个比值与设定稿误差 ≤3%。
3. **表情可读性**：同一张脸上取 5 个情绪 × 3 个口型共 15 帧，**旁人（老板）不看字幕能说出情绪**才算过。

前两条我做，第三条只能由老板判。

## 5. 已知会踩的坑（继承前面两天的实测）

- 中景构图：头心放画幅 y≈0.31H，头高≈0.24H；低于此会"大头贴"，高于此会"远景观光客"。
- 躯干画到画幅外，否则底部一条平切硬边。
- 手臂必须画在躯干**之前**，并且与躯干之间留暗缝，否则读成"钟罩"。
- 头发内缘必须是**一条平滑发际线**；中间凹口会让额头看起来像戴帽子。
- 鼻子只给一组结构；任何"第二层"都会立刻被看成缺陷。
