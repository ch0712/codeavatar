# 3D 代码几何实验路线：评估结论（2026-11-04）

> 阶段 4 第 4 项。判定维度按 ROADMAP：身份稳定、表演质量、性能、制作成本。

## 结论：**不并入主线，关闭该实验路线（直至 2D 体系遇到硬表示边界）**

## 评估依据

1. **平移视差已给出下界**（docs/AB-2.5D.md）：同角色 2.5D 层视差原型实测
   差异占比仅 0.32%（低于可辨阈值），且遮挡重排在纹理重叠区穿帮。
   3D 代码几何（真网格 + 透视相机）能提供的立体增益在**纯正面口播构图**
   下同样主要来自转头/侧视——而当前产品形态（竖屏口播、画中画解说）
   的受控视角范围很窄（|yaw| ≤ 0.8），3D 的优势区间没有被打开。
2. **制作成本不对称**：3D 几何需要每个角色建模/绑定（网格、UV、骨骼），
   与"设定稿进去、角色出来"的零人工建角目标直接冲突；2D 描摹流水线
   的全部机检（gate/口型/身份 golden）都要为 3D 重写。
3. **身份稳定风险**：3D 渲染受光照/相机/材质参数影响，"同输入逐字节可复现"
   的硬纪律需要额外锁定渲染器版本与参数（当前 SVG 渲染天然确定）。
4. **性能**：3D 实时渲染在 CI 无 GPU 环境的确定性回归成本高。

## 重新打开的条件（写死，防止反复横跳）

- 产品形态需要**大角度转头/转身**（|yaw| > 1.5 的受控视角成为常规需求）；或
- 2D 体系被证实无法表达的特效成为卖点（如真实光影/体积）；且
- 愿意接受建角成本从"零人工"退到"每角色小时级"。

满足前，资源投入优先级：网格形变（脸曲面随 yaw 非均匀变窄，可复用
`depth.ts` 实验通道）> 光照材质（第 3 项，纯 2D 可做）> 3D。
